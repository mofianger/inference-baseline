对照范围

官方 Backbone Fused 开关除了融合 Norm、激活和量化，还合并 QKV GEMM，并将 LLM Attention 从 FP16 展开 K/V 路径换成 BF16 FlashAttention-2 GQA。测得的是整套官方 Backbone 优化路径的收益。

Kernel 详情来自独立 eager 调用的 NVTX 与源码映射。耗时来自正常 CUDA Graph 的 Nsys 采集；映射运行中的逐调用同步不参与计时。未匹配的 Kernel 保留原名。阶段跨度含间隙，Kernel 耗时之和不等于跨度。
