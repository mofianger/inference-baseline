# PhyAI / π0.5 / SM120

Recipe `phyai-pi05-sm120-bf16-graphs-v1`，配置 [pi05-phyai.json](../../configs/5090/pi05-phyai.json)。
协议 `pi05-base-b1-v3-model-only-v1`，同一 canonical checkpoint；使用 `third_party/phyai/.venv`。

inline `Engine.step(PI05Request)` 包含 vision、prefix 和完整 Euler 去噪；BF16 参数与原生 FP32 stem。三个阶段均捕获 CUDA Graph，prefix 使用长度 buckets；实际 bucket 列表及其他图状态记录在 summary。固定 FlashInfer workspace=256 MiB，以满足本配置的注意力临时缓冲需求。

参数严格加载，输入 embedding 的 tied alias 映射到引擎期待的 lm_head 名称。CLI 将 venv bin 加到 PATH，让 JIT 构建能找到 ninja。
其他 vision dtype、量化及 kernel policy 属于独立候选 Recipe，本轮未测。
误差与完整来源见 [报告](../../reports/2026-10-23-5090-pi05/README.md)。
