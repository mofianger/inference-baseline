# FlashRT / π0.5 / SM120

已测协议：`pi05-base-b1-v3-model-only-v1`；官方 base 的同一 FP32 canonical checkpoint。
固定引擎提交与实际 kernel 二进制 SHA256 见 [报告](../../reports/2026-10-23-5090-pi05/README.md) 中各 summary。

| Recipe | 配置 | 实际路径 |
|---|---|---|
| flashrt-pi05-sm120-bf16-v1 | [BF16](../../configs/5090/pi05-flashrt-bf16.json) | FORCE_BF16=1，关闭 FP8，完整 CUDA Graph |
| flashrt-pi05-sm120-fp8-v1 | [FP8](../../configs/5090/pi05-flashrt-fp8.json) | prefix/decoder FP8 混合精度，完整 CUDA Graph |
| flashrt-pi05-sm120-nvfp4-v1 | [NVFP4](../../configs/5090/pi05-flashrt-nvfp4.json) | prefix FFN 与 decoder NVFP4 路径，其余混合精度，完整 CUDA Graph |

GPU_ARCH=120；开启 `FLASHRT_ENABLE_PI05_SKINNY` 和 `FLASHRT_ENABLE_PI05_NVFP4`，构建脚本 [build_flashrt_pi05.sh](../../scripts/build_flashrt_pi05.sh)。依赖包含 ml-dtypes 0.5.4。使用仓库内 `third_party/FlashRT/.venv`。

每次计时内重新计算 GPU token embeddings、更新 mask/位置/RoPE，复制图像和公共初始噪声，执行 vision/prefix/10 步去噪，再取得完整 GPU action。cache_frames=1，不跨请求复用图像特征。

1 个固定合成样本校准，seed=0；不代表真实场景校准。保留上游 scale outlier 警告。无数值通过阈值，比较低精度路径时必须同时参考误差。
其他 prefix/decoder 混合组合和其他硬件仍为候选，不能外推为已测。
