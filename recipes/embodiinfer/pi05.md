# EmbodiInfer / π0.5 / SM120

Recipe `embodiinfer-pi05-sm120-request-graph-v1`，配置 [pi05-embodiinfer.json](../../configs/5090/pi05-embodiinfer.json)。
协议 `pi05-base-b1-v3-model-only-v1`，官方同一 canonical checkpoint；独立环境 `third_party/EmbodiInfer/.venv-pi05`，LeRobot 0.5.1。

调用 native inference/embeddings 的 `Pi05Runtime.request`，捕获覆盖 embeddings、prefix 和完整去噪的 request CUDA Graph；单独 prefix/loop 图缓存为 0 是此路径的正常状态，request_graphs=1 才是实际证据。禁用通用 fused_ops；保留 LeRobot 原生完整 vision/projector FP32，其余按原生策略 BF16/FP32。

报告记录实际图缓存计数及计时前后不变性。分段 prefix/loop 图、其他融合算子和量化路径未在本轮测试。
误差、源码提交及软件版本见 [报告](../../reports/2026-10-23-5090-pi05/README.md)，不宣称数值验收通过。
