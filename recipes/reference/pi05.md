# OpenPI reference / π0.5 / SM120

配置 [pi05-reference.json](../../configs/5090/pi05-reference.json)，协议 `pi05-base-b1-v3-model-only-v1`。
官方 `pi05_base`，固定 OpenPI 提交的转换函数，FP32 构建导出；严格加载 811 个 action sampling 使用的参数，删除两个未使用词表输出头。同一 canonical 权重用于所有引擎。

PyTorch eager `sample_actions`，官方选择性 BF16/FP32 策略，显式公共噪声和 10 步 Euler。模型专用环境、Transformers 官方 replacement 与依赖快照见 [指引](../../docs/guides/pi05-5090.md)。
此实现生成冻结 reference actions，也是计时参考行；并非全 FP32 数值真值。报告中 reference 的小误差表示重运行对冻结输出的差异。
